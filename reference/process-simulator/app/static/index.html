Zapis sesji

Zachowaj plik JSON albo skopiuj poniższy zapis. Zawiera historię i aktualnie oglądany krok.

Wznów sesję

Wklej zapis lub odczytaj plik JSON. Poprawny zapis zastąpi sesję w pamięci. Błędny zapis nie zmieni stanu. Przed zastąpieniem zachowaj bieżącą sesję.
